# International Coverage

UOGW is not US-only. Indexes and samples include foreign and international networks.

## Worldwide city samples

Daily surface snapshots for **30+ cities** across continents (`layers/ground/samples/`):

| Region | Examples |
|--------|----------|
| North America | Casey IL, Chicago, Houston, Toronto, Mexico City, Honolulu, Anchorage |
| South America | São Paulo, Buenos Aires, Lima |
| Europe | London, Paris, Berlin, Madrid, Rome, Oslo, Stockholm, Reykjavik, Moscow, Istanbul |
| Africa | Cairo, Nairobi, Johannesburg, Lagos |
| Middle East | Dubai |
| Asia | Mumbai, Beijing, Tokyo, Seoul, Singapore, Bangkok, Jakarta |
| Oceania | Sydney, Auckland |

## GHCN global station index

NOAA **GHCNd** inventory is global. UOGW stores daily country counts, top-country summaries, and sample stations under `layers/ground/ghcn/`, with a pointer to the full NOAA list.
