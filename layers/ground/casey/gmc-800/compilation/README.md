# Aerostratospheric radiation index compilation

Downloadable pack for the Casey, Illinois ionizing-radiation station shown on xDataHub.

- Site: MSDS-GMC800-CASEY (39.2974, -87.9818)
- Instrument: GQ Electronics GMC-800
- Detects beta, gamma, and X-ray ionizing radiation
- Units: CPM (counts per minute) and µSv/h (dose-rate estimate)

## Files

- `radiation-index-compilation.csv` — daily means plus one WINDOW summary row
- `radiation-index-compilation.json` — same series with site metadata
- `../latest.json` — current ingest snapshot used by the live board
