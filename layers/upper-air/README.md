# Upper-air layer

Radiosonde, pilot balloon, and reference upper-air networks.

## Primary

- **NOAA IGRA** — daily Y2D directory indexes under `igra/`
- Links to **GRUAN**, **CUON**, **University of Wyoming soundings**

## Policy

UOGW stores **indexes and metadata**, not multi-decade bulk sounding archives. Full files remain at NOAA NCEI and partner hosts.

## Automation

`igra-index-daily.yml` runs independently on GitHub Actions.
