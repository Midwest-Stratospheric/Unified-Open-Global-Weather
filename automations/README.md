# Automations

GitHub Actions live at repository root: `.github/workflows/`.

| Workflow | Purpose |
|----------|----------|
| `msds-ground-daily.yml` | Casey ground → msds-data |
| `igra-index-daily.yml` | NOAA IGRA Y2D index |
| `ndbc-marine-daily.yml` | NDBC station index |
| `catalog-rebuild.yml` | Status rollup |
| `open-sources-daily.yml` | SWPC space weather, NWS regional obs, Open-Meteo archive, IGRA ILX soundings, UV/ozone |

These run independently of midwestsds.com.
